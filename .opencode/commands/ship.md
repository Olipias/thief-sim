按项目 `AGENTS.md` 的「完成定义」收尾当前这批改动（不要跳步）：

1. 运行 `tools/verify.sh`，必须全绿；失败则先修复再继续。
2. 更新 `CHANGELOG.md`：顶部新增条目。原型期版本规则：一批功能 = `v0.x.0`，修复/杂项 = `v0.x.y`；包含日期与「新增 / 修改 / 修复 / 测试」分类；写清改了什么、为什么，禁止「优化若干」类描述。
3. 更新 `README.md`「开发进度」与 `docs/ROADMAP.md` 对应任务状态（`🚧 进行中` → `✅ 完成`，保留记录不删条目）。
4. 架构 / 决策有变化时：同步 `docs/ARCHITECTURE.md` / `docs/DECISIONS.md`；涉及真实文物时：按 `docs/SOURCES.md` 规则登记来源与演绎分界。
5. 汇报：新版本号、改动摘要（3–6 条）、测试总数（从 verify 输出读取）、遗留问题（如有）。
