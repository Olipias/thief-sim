# 小偷模拟器

## 它的主要玩法

* 像素rpg操控
* 有npc敌对阵营，即警察会进行逮捕
* 一步步通过卖钱去升级，有主线剧情

## 剧情背景

进入了一个神偷组织，组织派任务去到某博物馆盗窃指定文物，每次偷窃必须带出指定物品，如有额外背包空间，可带出其他文物用于自行出售获取金钱，来升级玩家自己的背包，道具等。玩家在偷窃过程中可能遇到警察，玩家需要使用道具或者精细操作来躲避被逮捕，被逮捕就意味这这一局游戏game over。同时，玩家在游玩中还能通过接触文物了解到背后的故事，也许会有文物附着的幽灵对玩家进行捣乱，或者讲述故事等等。

## 设计愿景（数位历史 capstone）

本作同时是数位历史专业的 capstone project：既要是一款玩家愿意主动玩下去的小偷模拟器，也要让历史通过**机制**而非贴皮融入——核心是「文物通灵」：幽灵是文物的当年主人与见证者，可能帮助玩家、捣乱或讲述真实历史。重点关卡构想为**大英博物馆**：取回近代被掠夺的中国文物后，玩家可选择卖给黑市或归还中国，选择将影响主线、幽灵态度与结局。游戏内的真实文物与事件均需标注参考来源，并明确区分史实与虚构演绎。详细设计约定见 `.opencode/skills/thief-sim/SKILL.md`。

## 维护与协作（AI agent）

* 开工前先读 [AGENTS.md](AGENTS.md)：硬性规则、常用命令、完成定义与多窗口协作协议。
* 任务认领与里程碑见 [docs/ROADMAP.md](docs/ROADMAP.md)；架构地图与改造配方见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 如何运行

需要 Godot 4.7（本机已安装为 `~/.local/bin/godot`）：

```bash
godot .                 # 启动游戏
godot --headless --script tests/test_logic.gd   # 逻辑单元测试
godot --headless res://tests/smoke_test.tscn    # 关卡集成测试
```

工具脚本（可重复生成占位资源）：

```bash
python3 tools/gen_placeholder_sprites.py   # 重新生成 assets/sprites 占位图
python3 tools/gen_museum_map.py            # 重新生成 src/levels/museum_map.json（含连通性校验）
python3 tools/gen_sfx.py                   # 重新生成 assets/sfx 复古音效
```
