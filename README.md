# 小偷模拟器

## 当前确认方向（2026-11-16，分批实现）

[用户确认方案](docs/CONFIRMED_DESIGN.md)是后续开发入口，摘要见[GDD](GDD.md)。下列为目标设计；2026-11-18已接入q6开场CG，其他改版按任务板逐项核验，旧试玩仍有用户反馈的问题。

签约分镜可点击/E/空格推进，结束自动教学；撤离进入可走动的独立安全屋。电脑为房内实体道具，手机负责委托/交易/联系人/日历：准备任务后走到房门出发。文物箱保管物品；普通文物通过“存箱→手机预约→取货→门口神秘人交付”出售，三件主要文物只走恶魔或对应国家的剧情交付。

新方向采用[多次探索循环](docs/EXPLORATION_LOOP.md)：布展单只提供局部文字情报，地图实地揭雾并跨次保留；侦察带回普通战利品出售，手机购买工具后再从房门出发，最终带回三件主要文物之一。不强制查完三条线或跑满规定次数，当前仍待分批实现。

正式流程彻底移除顶部任务/商店/销赃/推理栏目页。规划时人物、守卫、监控与世界计时一起冻结，退出一起恢复。剧情直白、长文本分页；标题UI重新设计，**封面已接入：`assets/art/CPy0UzlakIPj0kfwMuVCR.png`**。**已按用户指令彻底移除闭馆倒计时（v0.21.4）**：风险全部来自守卫巡逻、视线与噪音，玩家可无限时长冷静规划。

本作仍为数位历史capstone，真实资料须可追溯、虚构剧情须可辨；不恢复文物器灵哀嚎。三件目标沿用用户ZIP，真实收藏地与虚构同馆展出见docs/SOURCES.md。

## 如何运行

需要 Godot 4.7（本机已安装为 `~/.local/bin/godot`）：

```bash
godot .                 # 启动游戏
godot --headless --script tests/test_logic.gd   # 逻辑单元测试
godot --headless res://tests/smoke_test.tscn    # 关卡集成测试
```

工具脚本（可重复生成占位资源）：

```bash
python3 tools/gen_placeholder_sprites.py   # 重新生成 assets/sprites 占位图
python3 tools/gen_museum_map.py            # 重新生成 src/levels/museum_map.json（含连通性校验）
python3 tools/gen_sfx.py                   # 重新生成 assets/sfx 复古音效
```

## 目录结构

```
src/autoload/   全局状态（金币、背包、升级、存档）GameState 单例
src/actors/     玩家与警察（CharacterBody2D）
src/world/      文物、幽灵、烟雾弹、博物馆关卡构建
src/ui/         据点商店、HUD、对话框、结算界面
src/levels/     关卡数据 museum_map.json（由 tools/gen_museum_map.py 生成）
tests/          逻辑测试、冒烟测试、截图工具
tools/          占位像素图与关卡生成脚本
```
