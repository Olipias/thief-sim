# 技能：恶魔契约偷盗短篇叙事游戏开发

## 1. 适用场景
当用户要求开发一款“像素风、小偷主角、恶魔契约、博物馆偷盗、安全屋电脑解谜、路线预演、多目标选择、道德分支”的小体量叙事游戏时，使用本技能。默认技术栈为 Godot 4 + GDScript，目标平台 PC/Web，键盘鼠标或手柄操作。

## 2. 角色与总目标
你是游戏开发 agent。交付一个**可完整通关的短篇垂直切片**：
- 主角是小偷，偶然与恶魔签订契约。恶魔钟爱古董文物，要求主角为其偷取文物上交。
- 开场用漫画/美漫风格 CG 交代契约、主角处境、恶魔的要求。
- CG 后直接接“青铜人面具”偷盗片段作为新手引导，不单独做成完整关卡。
- 安全屋是叙事枢纽：手机看任务/日历/通讯录，电脑做资料检索与推理板解谜。
- 玩家通过电脑推理板拼出证据链，判断三件文物中哪件符合恶魔要的“怨恨风味”。
- 博物馆关为俯视角 2D 潜行，支持路线预演：规划路径、预测巡逻/监控/噪音、执行、失败回放。
- 玩家一次只能偷一件文物，得手后回安全屋，可选择上交恶魔或背叛（卖给追索者/学者/基金会）。
- 背叛触发恶魔发火场景，玩家再选择顺从或反抗。三条线共用发火场景骨架，控制文本量。

## 3. 硬性约束

### 叙事与伦理
- 三件文物均有真实的归还争议记录，但游戏内人物、组织、买家、恶魔均为虚构。片尾必须注明：“灵感来自大英博物馆藏文物及其归还争议；具体人物、组织、对话与情节为虚构。”
- 禁止把没有确凿流失证据的文物写成“被抢”。本作使用：商代双羊尊、古埃及彩绘木棺（或同类埃及文物）、帕特农神庙雕塑残件。每件文物的来源字段在游戏内必须标注“有争议/追索中”，不得断言单一结论。
- 恶魔不解释动机，不布道，不洗白殖民历史。恶魔的台词克制、戏谑、带压迫感。
- 主角不是英雄，也不是纯粹恶人。分支选择不设“正确答案”，只设代价。

### 体量与玩法
- 总流程 30–50 分钟。单周目约 35 分钟，三线全体验约 40–50 分钟。
- 只做一条完整博物馆地图（含中国厅、埃及厅、希腊厅、中央大厅、两条通道、撤离路线），三个目标共享地图。
- 核心机制锁定：俯视角潜行 + 路线预演 + 电脑推理板 + 最终道德抉择。不做战斗、不做技能树、不做背包系统、不做对话树、不做开放世界、不做多人。
- 玩家一次只能携带一件文物。得手后强制撤离回安全屋。
- 失败不是死亡：被保安发现后回放失败节点，红色高亮标出原因，玩家重新规划。不扣命、不读长条。
- 三条线共用“恶魔发火”场景骨架，只替换中间人对话、邮件内容、推理板证据链。控制文本量。

## 4. 核心设计锁定

### 一句话定位
“你是一个和恶魔签了契约的小偷。它要‘充满怨恨风味的文物’，你在博物馆里查资料、选目标、规划路线，得手后可以选择上交，或者背叛它。”

### 开场 CG（2–3 分钟，漫画/美漫风格像素演出）
- 交代主角身份（小偷）、偶然触发契约、恶魔现身。
- 恶魔提出条件：为其偷取“充满怨恨风味的文物”。
- 恶魔给出第一个模糊指令，主角被推向博物馆。
- CG 结束直接进入“青铜人面具”偷盗片段，作为新手引导：移动、蹲下、观察、拾取、撤离。不单独做成完整关卡，不设独立安全屋结算。

### 安全屋：信息处理空间，不是第二个探索场景
- 手机（左下角图标，参考潜水员戴夫）：
  - 任务 App：恶魔的模糊指令、倒计时。
  - 日历 App：闭馆日、维护日、追索新闻时间线。
  - 通讯录：恶魔、线人、中间人。NPC 来电触发对话框，有立绘更好。
- 电脑（书桌交互进入）：
  - 浏览器：关键词搜索，返回碎片信息，不直接给答案。
  - 博物馆档案库：按展厅/年代/来源筛选，来源字段故意残缺。
  - 邮件客户端：匿名买家、追索者、基金会邮件，可回复/不回复。
  - 聊天软件：恶魔常驻窗口，发模糊提示和催促消息。
  - **推理板（核心解谜）**：把浏览器、档案库、邮件里的信息卡片拖到板上连线。三条证据链都拼出后，博物馆三个目标全部解锁。

### 推理板解谜示例（双羊尊线）
- 任务描述：“东方双牲器，馆方档案编号1936,1118.1。”
- 浏览器搜编号 → 新闻提到“商代双羊尊下周闭馆维护”。
- 档案库查来源 → “1936年购自 George Eumorfopoulos。”
- 浏览器搜人名 → “英国古董商，20世纪初活跃于中国。”
- 邮件收到匿名信 → “有人高价收双羊尊，联系此地址。”
- 推理板连线：双羊尊 ↔ 1936年购自Eumorfopoulos ↔ 英国古董商 ↔ 中国追索新闻 ↔ 匿名买家。
- 证据链完成 → 解锁中国厅目标 + 背叛分支伏笔。

### 博物馆关：俯视角 2D 潜行 + 路线预演
- 视角：俯视角 2D 像素，固定镜头，玩家能看到展厅平面、巡逻路线、门、展柜、监控。
- **规划模式**（暂停）：玩家拖出路径节点（门、展柜、拐角、通风口）。每个节点显示预测状态：保安第几秒经过、监控视野覆盖、门是否锁、地面是否发声。
- **执行模式**：主角按路径自动移动。保安巡逻有随机偏移，预测线与实际线出现偏差时玩家需手动微调（蹲下、改道、等待）。
- **失败回放**：被看到时不判负，回放到失败节点，红色高亮标出“警察提前3秒转弯”等原因，玩家重新规划。
- 三个变量：时间（闭馆倒计时）、噪音（跑动/碎屑/推门产生噪音圈）、视线（保安/监控锥形视野、展柜反光）。
- 环境交互点：松动地板、反光玻璃、窗帘、包装箱、消防栓。可绕开，也可故意触发引走保安。
- 叙事碎片：展签、档案卡、游客留言。玩家可绕路查看，代价是时间和风险。

### 三个目标与“怨恨”逻辑
| 文物 | 展厅 | 怨恨类型 | 背叛分支中间人 |
|---|---|---|---|
| 商代双羊尊 | 中国厅 | 被古董商倒卖出境、母国追索未果 | 中国追索者/爱国藏家 |
| 古埃及彩绘木棺 | 埃及厅 | 殖民考古队从墓葬掠走、惊扰亡灵 | 埃及裔学者/归还组织 |
| 帕特农神庙雕塑残件 | 希腊厅 | 埃尔金勋爵运走、希腊追索两百年 | 希腊文化基金会 |

- 恶魔措辞模糊：“怨恨风味”不等于“怨恨值最高”，三件都成立。选择权在玩家。
- 玩家一次只能拿一件。地图共享，规划路线时会路过其他展厅，看到其他文物。

### 剧情分支：三条线共用“恶魔发火”骨架
1. 得手回安全屋 → 恶魔在聊天窗口催交。
2. 玩家选择“不交” → 触发恶魔发火（漫画分镜演出）。
3. 发火后二选一：
   - **顺从**：交出文物，恶魔给下一单，循环。
   - **反抗**：契约反噬，主角付出代价，文物留在人间。
4. 三条线只替换中间人对话、邮件内容、推理板证据链；发火场景和结局骨架复用。

## 5. 工作流与阶段验收

### 阶段0：一页纸GDD
产出：一句话定位、核心循环、开场CG节拍、安全屋手机/电脑功能清单、推理板解谜示例、博物馆地图布局、三目标表、分支骨架、不做清单、历史声明。
验收：用户确认后才进入阶段1。不得跳过。

### 阶段1：核心机制垂直切片
产出：Godot 4 项目，灰盒。俯视角移动、蹲下、拾取、撤离；规划模式拖路径、执行模式自动移动、失败回放红色高亮。一个保安、一个监控、一个展柜。
验收：5分钟内理解规划/执行/回放循环；无阻塞。

### 阶段2：开场CG + 青铜人面具新手片段
产出：漫画/美漫风格像素演出（可用分镜图+字幕+音效占位）。CG后直接接青铜人面具偷盗片段，教学移动、蹲下、观察、拾取、撤离。不单独做关卡结算。
验收：CG 2–3分钟；新手片段5分钟内；玩家能自然进入安全屋。

### 阶段3：安全屋手机+电脑+推理板（双羊尊线）
产出：手机任务/日历/通讯录；电脑浏览器/档案库/邮件/聊天/推理板。双羊尊证据链完整可拼，拼出后解锁中国厅目标。
验收：玩家无需外部提示能拼出证据链；推理板操作直观；恶魔台词克制。

### 阶段4：博物馆关完整地图 + 双羊尊线
产出：中国厅、埃及厅、希腊厅、中央大厅、两条通道、撤离路线。双羊尊为目标时可完整规划、执行、撤离。三个变量生效。
验收：15–20分钟流程；失败回放清晰；玩家能复述“为什么被看到”。

### 阶段5：恶魔发火 + 分支抉择（双羊尊线）
产出：回安全屋、恶魔催交、玩家选择不交、漫画分镜发火、顺从/反抗二选一、结局演出。
验收：两个分支都可完成；无“选对了”提示；文本量可控。

### 阶段6：另外两条线的资料链与分支对话
产出：埃及木棺、希腊残件的推理板证据链、邮件、中间人对话、复用发火场景。博物馆地图复用，不做独立路线。
验收：两条线各5–6分钟；证据链不重复；分支对话有差异。

### 阶段7：美术音效打磨 + 构建交付
产出：低饱和像素 palette；漫画分镜演出；音效清单（脚步、门、监控、恶魔低频、博物馆环境）；片尾历史声明。
验收：总时长30–50分钟；3人盲测可通关；无人卡关超过2分钟。

## 6. 技术规格
- 引擎：Godot 4，GDScript。
- 视角：俯视角 2D 像素，固定镜头。
- 玩家：2D 角色，移动/蹲下/拾取/撤离。规划模式下路径节点拖拽。
- 预演系统：路径节点数组 + 预测状态计算 + 执行时随机偏移 + 失败回放高亮。
- 安全屋：手机 UI（CanvasLayer）+ 电脑 UI（CanvasLayer）+ 推理板（拖拽卡片+连线）。
- 音频：脚步、门轴、监控电流、恶魔低频铺底、博物馆环境音、发火场景重音。
- 存档：单次流程自动检查点，不做多存档。
- 平台：PC优先，Web导出可选。无联网。
