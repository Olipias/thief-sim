## 0. 目标与约束

**目标**：文物机制要「寓教于乐」——玩家在游玩中真的学到历史；文本量要够，但呈现不能平铺直叙。

**约束**：
- 学术规范（`docs/SOURCES.md`）：真实文物必须登记可核对来源、明确区分史实与演绎；虚构文物不得冒充真实。
- 复用现有系统：`DialogueBox`（打字机对话）、`RelicView`（3D 转台）、任务终端（手机）、背包、3D 渲染管线（`tools/blender` + `tools/gen_relic_sprite.py`）。
- 美术方向对齐 `docs/ART_DIRECTION.md`：**B 绢本志怪**用于通灵/文物特写层，**D 黑墨朱印**用于档案/闪回 UI，UI 叙事包装见该文 §2.7。
- 并行窗口纪律：见 §6。

## 1. 现状诊断（以青铜面具为例）

| 环节 | 现在有什么 | 问题 |
| --- | --- | --- |
| 拾取 | toast 一句「已放入背包」 | 无信息量 |
| 故事 | `CATALOG.mask.story` 一句话（虚构） | 与历史无关、无层次 |
| 幽灵 | 1 句台词 + 哀嚎引警 | 只当干扰物，没当角色 |
| 目标物 | 2 格形制 + 手机任务页 | 只有"要偷什么"，没有"它是什么" |

结论：**缺的不是文本量，而是"文本的载体与节奏"**——需要让玩家"做点什么"来换取信息，并把史实与演绎分层呈现。

## 2. 四个呈现预案

### 预案 A：器灵对谈（对话树 + 展签卡）

- **概念**：文物有器灵；通过对话"倾听/追问"，分三段解锁它的故事。
- **玩家在做什么**：拾取后器灵跟随；交互进入对谈；每段给出 2–3 个选项（倾听 / 追问细节 / 索要情报 / 承诺带它走）。
- **文本呈现**：
  - 对话按「绢本手卷」风格：说话人朱砂签条 + 打字机 + 情绪影响语速与抖动（B/D 方向）；
  - 每解锁一段，浮出一张**展签卡**（米白纸 + 金线 + 朱印）：3–5 行史实 + 一行来源（SOURCES 编号），与器灵台词**视觉分离**——这是"史实/演绎分界"的载体；
  - 选对方向 → 解锁下一段；选错 → 器灵沉默或转移话题（不惩罚，留钩子）。
- **寓教于乐**：追问本身就是"探究历史"；对话里可以自然放进"史料 vs 传闻"（例：器灵说"他们说是抢走的"，展签卡补"可考的是 1936 年购自……传闻无从证实"）。
- **资产/文本量**：无新美术；每件文物 3 段 × 8–12 句 + 3 张展签卡（约 400–600 字/件）。
- **工作量**：中（对话树 + 展签卡控件）。
- **优缺点**：复用最多、文本承载力最强、可互动；但本质仍是"读"，吃文案质量。

### 预案 B：端详 · 物证勘查（放大镜热点）

- **概念**：文物可「端详」——大图 + 可点击热点（铭文 / 纹饰 / 裂痕 / 修补痕 / 编号标签），点开讲一小段。
- **玩家在做什么**：背包或手机里选「端详」→ 大图界面 → 点热点收集细节 → 集齐解锁完整档案。
- **文本呈现**：热点聚焦（画面变暗、热点脉冲）+ 2–3 行短句：**史实一句 + 器灵一句**，绝不堆长段。
- **寓教于乐**：发现式学习，与真实"看展"行为同构；自己点出来的知识记得最牢。
- **资产**：每件文物一张大图（3D 渲染管线可直接出图；无 3D 的文物先用像素大图）+ 热点数据（坐标 + 文本）。
- **工作量**：中高。
- **优缺点**：最"博物馆"、最直观；但每件文物都要图，成本随文物数增长。

### 预案 C：历史闪回小剧场（分镜 + 旁白）

- **概念**：关键节点触发 2–4 格闪回：泛黄/绢本画面 + 逐句旁白 + 画面元素高亮（讲到"铭文"时铭文亮起），最后回到现实。
- **玩家在做什么**：触发即观看（可加速/跳过）；关键处插入 1 个选择（例："相信传闻 / 等证据"）。
- **文本呈现**：分镜 + 字幕逐句推进 + 音效（铸造声 / 火声 / 低语）；史实旁白与器灵口吻用不同字色与位置区分。
- **寓教于乐**：把史料变成"事件"，情绪记忆最强；适合"圆明园传闻"这类需要表态的题材。
- **资产**：每段 2–4 张画面（现有素材调色 + 3D 渲染 + 程序生成均可）。
- **工作量**：高。
- **优缺点**：记忆点最强、最适合做"高光"；但不宜承载大量文本，宜少而精。

### 预案 D（长期）：据点档案页 · 考据拼图

- **概念**：把物证（拓片 / 残页 / 旧标签）拼到文物的时间线上；拼对解锁史实条目，拼错给出"此说与史料不符"的解释。
- **寓教于乐**：直接训练史料辨析——这正是数位历史专业的核心能力；天然容纳"传闻 vs 史实"。
- **工作量**：高（新系统 + UI + 数据）；建议放 M5 P1 之后。

## 3. 推荐组合与「青铜面具」测试方案

**组合**：**A 为基础层（所有文物通用）+ B 为端详层（有图的文物）+ C 为关键文物高光（每关一次）+ D 为长期收集**。

**面具测试走 A + B**（成本可控、效果可见）：

1. **史实锚点建议（推荐）**：把「青铜面具」锚定为真实文物——**城固/洋县商代青铜人面具**（城洋铜器群，商代晚期，陕西汉中湑水河沿岸出土；陕西历史博物馆 / 城固县博物馆藏）。面具上那个"三千年微笑"是极好的叙事钩子。实施时先在 `docs/SOURCES.md` 登记（S-002，含馆藏页与论文）。
   - 备选：保留"虚构面具"只测机制——但"寓教于乐"就落空了，不推荐。
2. **三段故事草纲**：
   - 初见 · 面具上的微笑：器灵自我介绍，含糊、戏谑（演绎）
   - 追问 · 汉中为什么有这么多商代青铜器：城洋铜器群与南北/巴蜀文化交汇（史实为主）
   - 结局 · 微笑的意思：它被埋藏、被挖出、被展出的经历 + 一个请求（演绎收束，呼应史实）
3. **端详热点（B）**：面具大图 3 个热点——「微笑的嘴」「目纹」「背面的铸痕/钮」。
4. **呈现细节**：对谈用 A 的展签卡分层；端详用 B 的热点短句；两处文本都遵守"史实一句 + 器灵一句"的密度上限。

## 4. 示例文本（青铜面具 · 片段）

> 目的：让作者判断语气、信息密度与"史实/演绎"的分界方式。全部文本实施时会逐条核对来源。

**初见（器灵 · 演绎）**

- 器灵：「又来个摸黑进来的。别怕，我不咬人——我连嘴都是铸出来的。」
- 器灵：「你盯我看了三秒。上一个盯我这么久的人，把我从土里挖了出来。」
- 选项：
  - A「你笑什么？」→ 器灵：「铸我的匠人先笑了。他说，面具要笑，神才肯来。」
  - B「你从哪来？」→ 器灵：「湑水河边。那地方后来叫城固。」
  - C「你能帮我吗？」→ 器灵（沉默两秒）：「先听我说完，再谈买卖。」

**展签卡 ①（史实）**

> **商代青铜人面饰**
> 商代晚期（约公元前 13–前 11 世纪）。陕西汉中城固、洋县一带的"城洋铜器群"出土，同类面具在当地窖藏中成批出现，常与铜泡、戈、牛首饰同出，可能与祭祀、悬挂装饰或器物附饰有关。
> 来源：见 `docs/SOURCES.md` S-002（实施时登记馆藏页/论文）。

**追问（史实 + 演绎交织）**

- 选项：「汉中离商都在千里之外，为什么会有这么多商代青铜器？」
- 器灵：「你以为只有一条路？铜、锡、盐、玉——商人的车队顺着汉水往南走，走到我们那儿。」（演绎）
- 器灵：「北边的人铸鼎，南边的人铸我们。同样的铜，长着不一样的脸。」（演绎）
- 展签卡 ②（史实）：城洋铜器群累计出土七百余件，学者认为其兼具商文化与巴蜀/地方特征，是研究商代南方铜料与文化交流的关键材料（实施时补具体文献）。

**结局（演绎收束）**

- 器灵：「三千年，我埋在土里也笑。你问为什么？——因为我知道，总有人会把我挖出来，问我同一个问题。」
- 器灵：「带我出去之后，替我看看湑水河。它还在的话，就说我来过。」
- 展签卡 ③（史实）：文物现状与收藏地（陕西历史博物馆 / 城固县博物馆），以及"出土与流传"的考据结论。
