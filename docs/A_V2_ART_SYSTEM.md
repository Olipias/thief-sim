# A v2 · 冷宫暖器 2.0：视觉系统提案

> 2026-10-21 · 概念与执行方案（未全面实施）
> 配套图：`docs/art_direction/A2_comparison_board.jpg`（现状 vs 目标）、`docs/art_direction/A2_room3_upgrade.jpg`（Room 3 概念稿）

## 0. 一句话

**不换方向，换执行。** 继续用 A「冷宫暖器」做常态玩法，但把预算从“再加一层滤镜”转到四件事：**角色 24×32、主文物成为画面主角、UI 博物馆标签化、B/D 叙事层只在该出现时出现**。

---

## 1. 现状诊断

以 `shot_bm_room3` 和实际游玩为准，当前 A 方向已经解决了“像不像一个夜馆”的问题，但还有四个明显短板：

| 问题 | 表现 | 后果 |
| --- | --- | --- |
| 角色精度不足 | 16×24，2 帧行走，轮廓/表情弱 | 玩家和守卫像“色块小人”，与展柜细节不匹配 |
| 主文物不够亮 | 双羊尊在玻璃柜里偏暗，玻璃高光/反射反而更抢眼 | 目标物不像“主角”，玩家第一眼找不到 |
| UI 压画面 | 教学提示 2 行居中、字号大；任务文字和场景争主次 | 截图显乱，潜行时遮挡守卫/光锥 |
| 房间同质化 | 六厅都有相似的墙板/红毯/黑框 | 换厅没有“换展厅”的记忆点 |

这些都不是“换画风”能解决的，而是**资产精度 + 画面层级 + UI 层级**的问题。

---

## 2. 为什么不建议再换一套方向

现有矩阵是对的：

| 层 | 方向 | 用途 |
| --- | --- | --- |
| 常态玩法 | A 冷宫暖器（全像素） | 78% 时间；统一、耐看、可读 |
| 文物互动/通灵 | B 绢本志怪 + 高精度特写 | 14%；奖励式画风 |
| 历史闪回/档案 | D 黑墨朱印 | 6%；史观表达 |
| 宣发/标题 | C 微缩夜馆 | 2%；第一眼惊艳 |

不建议的方案及原因：

- **全流程 B 工笔/绢本**：好看但成本高、帧间一致性难，且会削弱“夜馆潜行”的冷感。
- **全流程 D 黑墨朱印**：风格强，但长时间游玩压抑，且红色/黑色会与警戒红冲突。
- **C 微缩 3D/HD-2D 做玩法**：镜头、碰撞、遮挡全部要重做，超出 capstone 范围。
- **照片/实拍纹理进玩法**：会重新引入“像素小人 + 实拍文物”的割裂，违反已定的两层规则。

**结论：保留矩阵，把 A 升级到 v2；B/D/C 只做“该出现时出现”的高光层。**

---

## 3. A v2 的视觉公式

> **冷底 + 暖器 + 青灵 + 金线**

- **冷底**：墙面/地面/阴影统一在蓝绿冷调，明度 10–35%。
- **暖器**：每间展厅只有一个暖光池，落在主文物/主展台上；明度 65–85%。
- **青灵**：器灵/通灵/交互反馈用青绿色（`#7FE0D0`），只占画面 1–3%。
- **金线**：博物馆的“展签/画框/栏杆/铜牌”用金色细线，负责把画面收住。

### 3.1 明度层级（每张截图都按这个检查）

| 层级 | 明度 | 内容 |
| --- | --- | --- |
| 背景 | 10–25% | 墙、天花、远处展柜 |
| 中景 | 35–55% | 地面、地毯、侧展台、守卫 |
| 主角 | 65–85% | 主文物、展柜光池、玩家轮廓光 |
| UI | 80–95% | 任务卡、金币、提示；只占边缘 |

**一条硬规则：每间展厅只有一个“最亮的东西”。** 如果任务卡比文物亮，就错；如果玻璃高光比文物亮，也错。

### 3.2 构图

- 主文物放在画面 **1/3 或中心偏上**，不要被 UI 压住。
- 用 **地毯/光锥/栏杆** 做 leading line，把视线推向展柜。
- 前景至少有一层 **暗部遮挡**（栏杆、展台边缘、门框），制造纵深。
- 角色不要站在画面正中央；玩家偏左/右，留出守卫与光锥的方向。

## 4. 角色：16×24 → 24×32

### 4.1 规格

| 项 | 现状 | A v2 |
| --- | --- | --- |
| 单帧 | 16×24 | **24×32** |
| 朝向 | 3 行（下/上/侧）× 2 帧 | 3 行 × 4 帧（待机 2 + 行走 2） |
| 颜色 | 4–6 色 | **8–10 色**（含 1px 深色轮廓 + 1px 冷色轮廓光） |
| 锚点 | 脚底，`position.y = -6` | 脚底，`position.y = -10` |
| 碰撞 | 10×8 | **不变 10×8**（只换视觉，不改手感） |

### 4.2 画法

1. **先剪影**：24×32 下，头 8×8、躯干 10×12、腿 4×8；先保证 1 格之外能认出“小偷/警察”。
2. **三值明暗**：暗部（冷）、固有色、亮部（暖）；不要用渐变色，保持像素块。
3. **轮廓光**：面向主文物的一侧加 1px 冷青/暖金轮廓光，和展柜光池呼应。
4. **材质区分**：小偷是布/皮革（哑光、软边），警察是制服/金属（硬边、铜扣高光）。
5. **动作**：待机 2 帧（呼吸/衣摆），行走 4 帧（脚交替 + 身体 1px 起伏），蹲伏 1 帧，交互 1 帧（伸手）。

### 4.3 迁移方式

- 保留 `player_sheet.png` / `police_sheet.png` 的 3 行结构，改为 3 行 × 4 列（`hframes=4`）。
- `Sprite2D.position.y` 从 `-6` 改为 `-10`；碰撞体/视锥/交互距离不动。
- 先替换玩家与 BM 守卫；教学关警察可沿用旧图，避免一次性重画所有 NPC。

**验收**：在 640×360 下，角色缩小到 1× 仍能一眼区分“小偷/守卫/平民”；行走 4 帧在 2 倍速下不抖。

## 5. 主文物与展柜：从“柜中物”到“画面主角”

### 5.1 三层精度

| 层 | 规格 | 用途 |
| --- | --- | --- |
| 玩法 | 32×32（主文物可 48×48） | 关卡内、背包/手机图标 |
| 特写 | 3D 扫描/高精度渲染（现有 `ram_zun.glb`） | 按 E 互动后的 2.5D 特写 |
| 档案 | 48×56 / 竖版 | 任务终端档案卡、图鉴 |

**不要把 4K 3D 渲染直接压成 32×32 当玩法图。** 高精度 3D 渲染适合特写；玩法图需要手工控制轮廓、明暗和高光，否则会糊成一团绿。

### 5.2 展柜

- **玻璃退后**：只保留 1px 冷色边光 + 顶部一条高光；不要大面积白色斜线（会像帐篷/绳子）。
- **文物前置**：文物在柜内占 55–65% 高度；底部加接触阴影，台座前加展签。
- **暖光池**：从上方打一个窄光锥，落在文物和台座上；光池边缘用抖动（dither）过渡。
- **地面倒影**：台座下方 8–12px 的暖色/青色倒影，透明度 10–15%，只做“有玻璃/大理石”的暗示。
- **展签**：台座正面一块米色小牌，写文物名；字比 UI 小一号，但必须可读。

### 5.3 材质配方

| 材质 | 暗部 | 固有色 | 亮部 | 高光/细节 |
| --- | --- | --- | --- | --- |
| 青铜（双羊尊） | `#1E3A2C` | `#4A7A52` | `#8FB06A` | 金绿 `#C9A25A`，铜绿斑点 |
| 玻璃 | `#4E7E8A` | `#7FA8B8` | `#D8F4F0` | 1px 边光，不画大面积白斜线 |
| 大理石 | `#6E6A60` | `#A8A294` | `#D8D0BE` | 细 veins，暖光下偏米色 |
| 红毯 | `#4A1018` | `#7A1A26` | `#A8303C` | 金线包边，少量菱形暗纹 |
| 木/漆 | `#2E1D12` | `#6B4A2F` | `#A57A4A` | 金漆描边，漆面高光 |
| 纸/绢 | `#8A826C` | `#C8BE9E` | `#E8DFC4` | 纤维/墨线，不要纯白 |

## 6. UI：博物馆标签化

### 6.1 尺寸（640×360 逻辑）

| 元素 | 建议 | 说明 |
| --- | --- | --- |
| 任务卡 | 200×30，左上 | 米色卡纸 + 金线 + 朱印“密档”；标题 12px |
| 小地图 | 64×44，任务卡下 | 深色平面图 + 金色墙线 + 红点目标 + 青点玩家 |
| 金币 | 90×22，右上 | 铜牌底 + 暖金字 |
| 警戒 | 56×22，金币下 | 朱印红，数字优先 |
| 背包/道具 | 160×36，左下 | 深棕皮革底；只显示当前道具与数量 |
| 交互提示 | 180×18，底部居中 | **10px，一行**；只在可交互时出现 |

### 6.2 规则

- **不要全宽居中大段文字**：教学/剧情文字改为底部 2 行内，4 秒淡出；重要信息进任务卡。
- **UI 只占边缘**：中间 60% 画面留给场景与光锥。
- **字体层级**：标题 12px / 正文 10px / 展签 8px；中文用 Fusion Pixel，标题可用 Noto Serif 做“标签/印章”。
- **颜色克制**：UI 底色不超过 3 种（米色卡纸、深棕皮革、朱红印章）；金色只做线，不做大面积填充。
- **可读性**：所有文字在 640×360 下 1× 截图必须能读；不要靠 2× 放大后才清楚。

## 7. 光与后期

- **三光**：暖 key（主文物，2700K）、冷 fill（环境，7000K）、青 rim（器灵/交互，5000K）。
- **光锥**：守卫手电是玩法信息，不是装饰；锥体边缘要清楚，中心可透；不要用大面积高斯模糊。
- **接触阴影**：角色/展台/栏杆脚下 2–4px 暗影；没有接触阴影会“飘”。
- **后期**：轻 bloom（只给暖光/青灵）、轻 vignette（不超过 15%）、颗粒 1–2%；**不要**全屏重噪点/色差，会破坏像素。
- **动效**：尘埃只在光锥内；器灵用 2–3 帧墨烟/青点；展柜玻璃每 4–6 秒一次短高光；不要持续闪。

## 9. 执行顺序

| 阶段 | 内容 | 产出 | 验收 |
| --- | --- | --- | --- |
| **P0** | 玩家 + BM 守卫 24×32；碰撞/锚点不变 | 新 sprite sheet | 1× 截图能认人；行走不抖 |
| **P1** | Room 3 展柜/光池/文物 48×48 重绘；玻璃退后 | 目标厅概念落地 | 第一眼看到双羊尊 |
| **P2** | 任务卡/小地图/提示条重做；教学文字下沉 | UI 套件 | 中间 60% 不被 UI 遮挡 |
| **P3** | B 特写 / D 闪回接入现有触发点 | 2 个叙事高光 | 不侵入常态玩法 |
| **P4** | 尘埃/倒影/器灵/轻后期 | 动效层 | 截图不糊、不闪、不抢戏 |

**如果只做三件事**：P0 角色 → P1 主文物光池 → P2 提示条缩小。这三件对“精美感”的提升最大。

## 10. 验收清单

- [ ] 640×360 原生截图，不依赖 2× 放大也能读清 UI/角色/文物。
- [ ] 每间展厅只有一个明度 65%+ 的主视觉；任务卡不超过 85%。
- [ ] 角色 1× 剪影可区分；行走 4 帧无抖动；碰撞/手感未变。
- [ ] 展柜玻璃只留边光；没有大面积白斜线/白框。
- [ ] 主文物有接触阴影 + 地面倒影 + 展签。
- [ ] 教学/剧情文字不再全宽居中压画面。
- [ ] 常态玩法无照片纹理；B/D 只在特写/闪回出现。
- [ ] `tools/verify.sh --visual` 通过，基线经人眼确认后才更新。

---

## 11. 不要做

- 不要给整个画面加同一层暗角/噪点来“统一风格”；先解决主体明度。
- 不要把 4K 扫描直接压成 32×32 当玩法图；会糊。
- 不要用大面积白色玻璃斜线表现“玻璃”；会像绳子/帐篷。
- 不要让任务卡/提示文字比文物亮。
- 不要在常态玩法里混入实拍文物/照片纹理。
- 不要为了“精致”把 16×16 瓦片改成 32×32 而不同步碰撞/寻路。
