| **6. 背叛交易与恶魔分支** | 撤离回安全屋后，**恶魔催交文物**。分支结构统一为两阶段：<br>① **交付阶段**：**直接上交恶魔**（走「契约履行·顺从结局」） vs **拒交恶魔**（触发「恶魔发火」漫画分镜）；<br>② **拒交后抉择**（在发火威慑下）：**屈服补交（顺从）** vs **反抗到底——私下转交中间人/归还线人（反抗结局：黑市交易或归还故土）**。一旦在阶段①直接交出文物，流程即进入顺从结局，不再触发反抗交易。 |

## 3. 三大目标文物与证据链设计（中国 / 埃及 / 希腊）

### 3.1 中国线：`ram_zun` 商代双羊尊（大英博物馆 Room 33 / 中国馆）
- **【可考史实】**：商代晚期（约前 1200–1050 年），高 45.1cm，重 10.6kg，南方青铜传统（传出自湖南，羊角分铸锁接、垫片工艺）；1936 年大英博物馆购自英国藏家 George Eumorfopoulos（馆藏号 `1936,1118.1`）。
- **【争议/流转】**：1936 年以前如何离开中国、具体出土地无公开档案；民间“1860 圆明园被掠”说无学术与馆藏记录支持。
- **【推理证据链（3 卡连线）】**：
  1. `电脑·档案库`：1936 年尤摩弗帕勒斯藏品入藏批次清单（锁定编号 `1936,1118.1` 与青铜厅展位）
  2. `电脑·邮件/论文摘要`：技术分析报告（南方分铸羊角 + 10.6kg 重量 + 展柜承重底座规格）
  3. `手机·通讯录/聊天`：内部线人发来的夜间巡逻交接单与展柜机械锁型号 → **三卡连线解锁：双羊尊盗取方案**。

### 3.2 埃及线：`egypt_stela` 埃及彩绘木乃伊面具/石碑（大英博物馆埃及馆，锚定真实馆藏：罗塞塔石碑 `EA24` / 阿蒙霍特普三世头像，游戏内取可单人背负的 **「第19王朝书吏彩绘墓碑」锚定大英底比斯藏品 `EA191`**）
- **【可考史实】**：新王国第 19 王朝（约前 1250 年），石灰岩彩绘祠堂形墓碑，出自底比斯（代尔麦地那工匠村），19 世纪初经英国驻埃及总领事 Henry Salt 收集，1823 年售予大英博物馆（馆藏号 `EA191`）。
- **【争议/流转】**：19 世纪初奥斯曼埃及帕夏统治时期，欧洲领事雇用当地挖掘队大规模采办文物运往伦敦与巴黎，引发当代关于殖民时期领事采办合法性的持续讨论。
- **【推理证据链（3 卡连线）】**：
  1. `电脑·档案库`：1823 年 Henry Salt 批次入藏记录（锁定编号 `EA191` 与埃及雕塑侧厅位置）
  2. `电脑·浏览器`：代尔麦地那工匠墓葬考据（识别碑文上的书吏姓名与红外防盗感应区）
  3. `手机·来电/邮件`：中间人发来的买方定制需求与侧廊通风口路线 → **三卡连线解锁：埃及墓碑盗取方案**。

### 3.3 希腊线：`greek_relief` 帕特农神庙骑手浮雕残块（大英博物馆杜维恩展厅，锚定真实馆藏：帕特农北翼浮雕 `1816,0610.28` 局部）
- **【可考史实】**：古典时期（约前 447–432 年），潘泰列克大理石，原属雅典卫城帕特农神庙外圈北侧浮雕带；1801–1805 年由英国驻奥斯曼帝国大使额尔金伯爵（Lord Elgin）团队从建筑上拆下运抵伦敦，1816 年由英国议会购入交大英博物馆（`1816,0610.28`）。
- **【争议/流转】**：希腊政府与国际学者长期质疑当年奥斯曼帝国许可文书（Firman）的原件存否与权限范围，要求归还雅典卫城博物馆；大英博物馆则主张 1816 年议会收购合法。
- **【推理证据链（3 卡连线）】**：
  1. `电脑·档案库`：1816 年议会收购目录与杜维恩展厅（Duveen Gallery）陈列图
  2. `电脑·浏览器`：卫城博物馆复原对照图（锁定正处于维护支架上、可拆卸的独立残块位置）
  3. `手机·聊天`：维修外包商流出的夜间脚手架密码与西通道钥匙位置 → **三卡连线解锁：希腊浮雕盗取方案**。

## 4. 不做清单（防膨胀护栏）

1. **不做任何倒计时**（无手机任务倒计时、无潜行限时、无逃脱读秒）。
2. **不做三张独立博物馆地图**：中国/埃及/希腊共用同一座大英博物馆（中央大厅 + 三展厅 + 双通道），靠证据链解锁对应展柜目标。
3. **不做自由文本输入的搜索框**：电脑浏览器与档案库采用**关键词标签点击 + 超链接跳转**，既保证“搜索不直接给答案、需跨应用比对”，又杜绝输入法与拼写卡关。
4. **不做三套独立的恶魔发火与结局系统**：三件文物共用同一套「催交 → 直接上交 / 拒交发火 → 顺从 / 反抗」状态机，仅替换文物专属台词与尾声历史卡。
