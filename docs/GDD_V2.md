## 1. 一句话定位与核心循环

- **一句话定位**：“你是一个和恶魔签了契约的小偷。它要‘充满怨恨风味的文物’，你在安全屋查资料、拼推理板选目标，在博物馆用**路线预演**规划潜行，得手后选择上交恶魔，或者背叛它。”
- **核心循环**：
  1. **开场与教学**：开场契约 CG（2–3 分钟，由 codex 绘制正式画作，代码先上分镜字幕占位）→ 直接接「青铜人面具」新手引导（移动、蹲下、观察、预演、拾取、撤离，5 分钟内，**无独立结算直入安全屋**）。
  2. **安全屋（信息处理空间，非探索场景）**：左下角**手机**（任务 / 日历 / 通讯录与来电）+ 书桌**电脑**（浏览器 / 博物馆档案库 / 邮件客户端 / 恶魔常驻聊天 / **推理板拖拽连线**）。
  3. **博物馆潜行 + 路线预演**：俯视角 2D 像素；**规划模式**（暂停拖出路径节点，显示预测：保安何时经过、监控视野、门锁状态、地面噪音）→ **执行模式**（自动沿路径移动，保安巡逻有随机偏移，玩家可随时手动蹲下/改道/等待微调）→ **失败回放**（被发现不判死，回放到失败节点，**红色高亮标出被发现原因**，直接重规划）。
  4. **得手与道德分支**：一次只能拿一件文物，得手强制撤离回安全屋 → 恶魔在聊天窗口催交 → **直接上交（顺从）** 或 **背叛不交（卖给追索者/学者/基金会）** → 背叛触发**恶魔发火分镜** → 二选一：**顺从（交出，进下一单循环）** 或 **反抗（契约反噬付出代价，文物留在人间）**。

## 3. 安全屋：手机与电脑功能规格

1. **手机（左下角图标）**：
   - **任务 App**：显示恶魔的模糊指令（“我要充满怨恨风味的旧物”），**无倒计时**。
   - **日历 App**：显示博物馆闭馆维护日、激光清洗排期、追索新闻时间线。
   - **通讯录 App**：恶魔、老猫（线人）、三线中间人（中国追索者 / 埃及裔学者 / 希腊文化基金会）；支持触发来电对话框。
2. **电脑（安全屋书桌交互进入）**：
   - **浏览器**：关键词检索（编号、人名、展厅），返回新闻与学术碎片，不直接给答案。
   - **博物馆档案库**：按展厅/年代/来源筛选，来源字段标注“有争议/追索中”且部分残缺。
   - **邮件客户端**：接收追索者、学者、基金会的来信，提供背叛交易/归还渠道与内部路线线索。
   - **聊天软件**：恶魔常驻窗口，发送模糊提示与得手后的催交质问。
   - **推理板（核心解谜）**：将从浏览器、档案库、邮件收集的卡片拖到板上连线，拼出完整证据链后解锁对应博物馆目标。

## 5. 博物馆关：俯视角潜行 + 路线预演规格

1. **单张共享大地图**：包含**中央大厅、中国厅、埃及厅、希腊厅、两条通道、撤离路线**。一次行动只能携带一件文物，得手后强制撤离回安全屋（移除多格贪心背包与普通杂物销赃循环）。
2. **路线预演系统（核心机制）**：
   - **规划模式（暂停）**：玩家在地面/关键点（门、展柜、拐角、通风口）拖拽生成路径节点序列。每个节点显示预测信息：**保安预计第几秒经过、监控扇区覆盖、门锁状态、地面噪音风险**。
   - **执行模式**：主角按规划路径自动移动；保安巡逻带轻微随机偏移，当预测线与实际位置出现偏差时，玩家可随时手动微调（**蹲下、改道、等待**）。
   - **失败回放（非死亡）**：被保安或监控发现时不判 Game Over 扣命，而是**定格并回放到失败节点，用红色高亮标出失败原因**（如：“保安巡逻偏移提前 2 秒转弯”、“跑动噪音圈惊动保安”、“进入监控扇区”），玩家直接重新规划。
3. **环境交互与叙事碎片**：
   - 环境点：松动地板、反光玻璃、窗帘、包装箱、消防栓/配电箱（可绕开或故意触发引开保安）。
   - 叙事碎片：展签、档案卡、游客留言（无器灵对话）。
