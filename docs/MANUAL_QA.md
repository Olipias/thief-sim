# 手动 QA 清单（约 2 分钟）

> 机器测不到的层面：观感、手感、节奏、音频、历史表述的可读性。
> **什么时候用**：每个版本收尾、任何涉及画面/关卡/叙事的改动之后、课程演示前。
> 用法：按顺序走一遍；不通过 → 记入 `docs/ROADMAP.md`「已知问题」，写清现象与复现步骤。
> 自动测试已覆盖的内容（开关/互斥/存档兼容/规则一致性）不在此重复，见文末对照表。

## 0. 启动（20 秒）
- [ ] `./play.sh` 能启动；窗口像素清晰（无拉伸模糊），中文不糊、不缺字
- [ ] 标题：新封面完整（屋顶小偷 + 博物馆正门）；开始/继续在角色手边、商店在入口台阶、声明/退出在右下角；入场/悬停动效自然
- [ ] 标题「商店」能直接进据点商店页；无存档时「开始游戏」直接开局，有存档时「新游戏」需二次确认
- [ ] 标题 →「继续 / 新游戏」进入据点；音效正常，无爆音
- [ ] 标题「声明与说明」能打开、可滚动、ESC / 关闭按钮可退出
- [ ] 据点：金币与商店价格显示正确；购买有反馈；两关的选关按钮都能进
- [ ] 撤离成功后战利品**没有**自动变成金币；在「销赃」页逐件/全部卖出后金币才增加

## 1. 城西博物馆（教学关，40 秒）
- [ ] 进门不被守卫手电直照（"巡逻避开门口"修复的人工确认）
- [ ] 走/疾跑手感正常（有速度差、有脚步声，不飘）
- [ ] E 拾取有提示与故事文本；背包满时提示"装不下"
- [ ] 被警察发现时 `? / !` 提示清晰；头顶黄色警觉条会随发现进度填充（约 0.5 秒），不会"无预警"进入追击；被抓有明确的结算反馈

## 2. 背包与手机（30 秒）
- [ ] B 开/关背包；鼠标拖拽整理顺畅；拖出方框能丢到地上并再捡起
- [ ] P 开/关手机；任务页 3D 转台流畅；档案页能端详文物
- [ ] 对双羊尊按 E：进入 2.5D 特写（黑场淡入 + 呼吸推近），E 拾取 / Esc 离开；关闭后恢复操作
- [ ] 展签卡：点开后按 P / ESC 能**逐层返回**（先关卡片、再关手机）
- [ ] 任何界面打开时游戏暂停；关掉后能立刻继续操作

## 3. 文物志与叙事（30 秒）
- [ ] 靠近目标按 E 触发器灵对谈；选项可用键盘选择
- [ ] 展签卡（米白纸卡）与器灵台词（深色框）**视觉上明确区分**
- [ ] 游戏内**不出现**「来源：docs/SOURCES.md」等学术引用（正式声明集中在标题页）
- [ ] 标题「声明与说明」里能查到真实文物、来源与虚构说明
- [ ] 幽灵/超自然内容在语境里能被理解为虚构，不冒充史实

## 4. 大英博物馆·中国馆（30 秒）
- [ ] 六间展厅主题可辨；地面/展品在夜色下看得清
- [ ] 目标双羊尊：3D 转台（混元资产细节：羊首/雷纹可辨）、背包图标、拾取后的器灵对谈都正常；2.5D 特写没有明显过曝/空洞/穿模
- [ ] 拿走双羊尊后打开手机「档案」页：端详图是清晰的特写（不是 24×24 图标放大），无热点时显示「暂无细节标记」
- [ ] 拾取双羊尊后：器灵哀嚎时能看到扩散波纹；警察被引来时有明确提示；靠近器灵按 E 交谈后 8 秒内不再哀嚎/引警
- [ ] 大英博物馆里同时被两名警察盯上时，能被哀嚎预警并靠移动/烟雾弹/安抚脱身（而不是"站着不动突然被抓"）
- [ ] 拿到目标才能从装卸区撤离；丢下目标后出口重新上锁

## 5. 音频与稳定性（20 秒）
- [ ] 脚步/拾取/警觉/被捕/幽灵等音效时机正确，无爆音/撕裂
- [ ] 连续开关界面 10 次、快速切关，无卡死/黑屏/输入失灵

## 自动 vs 手动 对照表

| 已由 `tools/verify.sh` 自动覆盖 | 只能人看 |
| --- | --- |
| 覆盖层开关/互斥/逐层返回（`test_input_flow`） | 操作手感、速度感 |
| 存档兼容/脏档/未来档（`test_save_compat`） | 画面可读性、像素清晰度 |
| 场景实例化/脚本编译（`test_scenes` / `test_scripts`） | 音频时机与音质 |
| 规则不变量/随机操作（`test_monkey` / `test_logic`） | 叙事节奏、历史表述是否得体 |
| 截图视觉回归（`tools/verify.sh --visual`） | 美术风格是否统一 |
| 内容一致性（`test_content`） | 关卡节奏是否有趣 |
