# 路线图与任务板（ROADMAP）

> **这是多个窗口/agent 共用的任务板。规则：先认领，后动手。**
>
> 1. 开工前把所选任务从 `📋 待办` 改为 `🚧 进行中｜<窗口/人>｜<日期>`，再动代码。
> 2. 一次只做一条主线；中途冒出的想法先记「候选池」，不要直接开工。
> 3. 完成后跑 `tools/verify.sh`、更新 CHANGELOG/README，再标 `✅ 完成`（**保留记录，不删条目**）。
> 4. 发现的问题但暂不修 → 记入「已知问题」。
> 5. 状态：📋 待办 ｜ 🚧 进行中 ｜ ✅ 完成 ｜ 🧊 搁置
>
> 注意：**代码与测试是事实来源**，本板快照可能滞后；开工前先跑一次 `tools/verify.sh` 确认基线。
