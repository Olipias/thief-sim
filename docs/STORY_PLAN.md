# 剧情内容冲刺计划（STORY_PLAN）

> 状态：**进行中**｜制定：2026-11-13｜负责人：plan（agent-mail：BlueLantern）
> 依据：`docs/STORY.md` v1 + 用户 2026-11-13 指令（#thief id 60）。
> 这不是最终验收阶段。本计划的目标是**把剧情做成可玩、可看、可验收的内容切片**，再进入最终验收。

## 1. 目标与完成定义

**一句话目标**：玩家从「新游戏」开始，能看开局动画、经历序章、打完两关、在雨夜岔路做出卖/还选择、看到对应结局，并回到据点看到世界的变化。

**完成定义（DoD）**：

- [ ] 新游戏 → 开局动画（可跳过）→ 序章 P-01 → 城西 M1（面具剧情）→ 据点 H-01/H-02 → 大英 M2（双羊尊剧情 + 标签场景）→ 岔路 M3 → E-01/E-02/E-03 → 据点 H-03。
- [ ] 剧情文本全部进入游戏（不是只躺在 `docs/STORY.md`）。
- [ ] 每个剧情节点都能和关卡/房间/触发器联动，不靠独立演示场景。
- [ ] 美术素材有完整清单、尺寸、命名、替换路径；占位可接受，但必须是「可替换的占位」，不是空白。
- [ ] `tools/verify.sh` 全绿；剧情相关新增测试覆盖存档旗标、输入流、分支与视觉回归。
- [ ] 旧存档可正常加载（剧情 flag 只增字段 + 默认值）。
- [ ] 学术边界：1860 圆明园说不得作为史实画面/旁白；结局声明原样出现。

## 2. 范围

**做**：

- 剧情数据层、剧情 flag、据点剧情事件、关卡内剧情触发器、标签/留言交互、双羊演出、岔路与三结局、开局动画。
- 剧情所需美术：开局分镜、7 张关键 CG、标签/留言 UI、双声道字幕样式、结局卡、据点/电话 UI（用户已点名）。
- 剧情验收：新增测试 + 视觉回归 + 手动 QA。

**不做（本冲刺）**：

- 新关卡、新追逐机制、警察 AI 重写。
- 全量 BGM、配音、多语言。
- 正式 3D/高精度美术替换（除用户点名的角色/警察/安全屋/电话 UI）。
- 大改背包/商店/经济系统。

- 新 UI/输入必须补 `tests/test_input_flow.tscn` 真实按键用例。
- 新存档字段必须补 `tests/test_save_compat.gd` 老档/脏档用例。
- 测试输出必须干净；不要往 allowlist 里随意加行。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 美术产能不足 | code 等素材，剧情无法集成 | 先做「可替换占位」：纯色 CG + 字幕 + 标签卡；code 不等最终图 |
| 并行改共享文件 | 冲突/返工 | file reservation + 只改必要文件 + 先读 `git diff` |
| 剧情 flag 破坏旧档 | 玩家丢进度 | 只增字段 + 默认值 + `test_save_compat` 覆盖 |
| 1860 说被画成史实 | 学术硬伤 | 只允许「观众留言/沈先生口中的网上抄的」；分镜/旁白禁止确定劫掠场景 |
| 开局动画锁输入 | 玩家卡死 | 任意键跳过 + 超时兜底 + 输入流测试 |
| 文本溢出 640×360 | 读不完/UI 破版 | 单句 ≤ 40 字、选项 ≤ 14 字；截图检查 |
| 隐藏结局条件过严/过松 | 玩家挫败/误触发 | 条件集中在一个函数 + 单测四种组合 |
