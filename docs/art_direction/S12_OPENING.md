# S-12 开局动画分镜：《雨里的门》

> 2026-11-13 · art（OrangeThrush）· 依据 `docs/STORY.md` §10
> 目标：40–45 秒、6 镜、4 句字幕；先出分镜/构图稿，最终 6 张 1280×720 分层 PNG 由 S-14 产出。

## 0. 一句话

用一场雨、一盏灯、一束展柜光，把「偷—听—选择」的基调立住；**不解释**，只让玩家在进入据点前安静 8 秒。

## 3. 逐镜构图/分层

### 镜 1 · 雨滴

- 画面：90% 黑；中央偏上一滴雨水打在铁皮/屋檐，冷白高光；第二滴在边缘。
- 层：`bg`（黑/铁皮暗纹） / `rain_hero`（水滴+涟漪） / `grain`。
- 光：无暖源；只有雨滴反射的冷光。
- 文字：字幕第一句在底部；不要加 Logo。

### 镜 2 · 洗衣店后屋（唯一暖源：熨斗/台灯）

- 构图：左侧门框内是玩家湿透的剪影；中右老猫低头熨衣；熨衣板斜切画面；白汽把两人隔开；窗上雨痕，招牌背面透一点红。
- 层：`bg`（后屋/窗/招牌背） / `cat`（老猫） / `player_silhouette` / `steam` / `rain_window` / `lamp_glow`。
- 光：台灯暖黄；玩家一侧冷蓝；老猫半张脸亮、半张脸暗。
- 细节：老猫手上有洗衣粉白斑；衬衫是湿的；蒸汽向上。
- 字幕：「人有。」

### 镜 3 · 博物馆正门（雨夜）

- 构图：低机位台阶 → 柱廊 → 穹顶；屋顶屋脊上一个人影（很小）；月亮在右上；雨丝斜切。
- 层：`sky`（云/月） / `museum`（柱廊/穹顶/暖窗） / `rain` / `roof_thief` / `street_glow`。
- 光：门廊暖黄、天空冷蓝；警笛光只在远处扫一下，不落在主角身上。
- 细节：卷帘门、石狮、湿台阶反光；人影不要看清脸。
- 字幕：「所以这行有一条规矩：不要问它从哪来。」

### 镜 4 · 青铜厅（唯一暖源：展台光）

- 构图：空展台居中；玻璃柜内极淡的两只羊影；尘埃在光柱里；画面静止。
- 层：`bg`（墙/地/展柜） / `spotlight` / `dust` / `sheep_reflection`（半秒淡入淡出） / `glass_glint`。
- 光：展台暖光；环境冷青；玻璃两层反光。
- 时间：8 秒，无字幕；不要加音乐，只有低频嗡鸣和呼吸。
- 边界：这是**空展台**，不是真实双羊尊；羊影是记忆/预兆，不是实物。

### 镜 5 · 展签微距

- 构图：展签占画面 2/3；字太小、失焦；一只手从右侧入画，指尖停在标签上方；焦点从指尖拉到纸纤维。
- 层：`bg`（展台/玻璃虚化） / `label`（不可读小字） / `hand` / `focus_blur`。
- 光：展柜暖光，纸面有纤维；手指边缘有冷轮廓光。
- **禁止**：不要让标签文字可读，不要伪造馆藏编号/年代；只画纸、光、手。
- 字幕：「直到有一天，你听见它回答。」

### 镜 6 · 标题卡

- 构图：黑底；标题「小偷模拟器」居中偏上；副标题一行；雨停后的安静。
- 层：`bg`（黑） / `title` / `subtitle` / `vignette`。
- 动效：淡入 1s → 停 4s → 淡出 1s；标题可以轻微呼吸，不要弹跳。
- 字幕：「有些东西被偷走两次。第一次是离开。第二次是被忘记。」
- 边界：标题字体用项目现有字体；不要用 AI 生成字。

## 5. 技术落点（@code）

- 新 `OpeningPlayer`（CanvasLayer 或 Control），在 `Main` 里「新游戏」后实例化。
- 6 个 TextureRect + 每镜 Tween：淡入/淡出/慢推/仰摇；总时长 40–45 秒。
- 2 秒后显示「按任意键跳过」；`_unhandled_input` 任意键/鼠标 → 1 帧淡出 → `show_menu()`/据点；不得吞输入。
- 结束后设置 `Game.opening_seen = true`（只增字段；存档兼容由 test 覆盖）。
- 失败兜底：素材缺失时跳过动画直接进据点；超时 50 秒自动结束。
