## 0. 一句话

七张关键 CG 只做「情绪节点」，不做全流程演出；标签/留言与双声道字幕是**可玩叙事**的一部分，必须在 640×360 下 1× 可辨。

## 1. 通用规格

| 项 | 规范 |
| --- | --- |
| 逻辑分辨率 | 640×360（整数缩放） |
| CG 制作尺寸 | **1280×720 PNG**（2×；可分层） |
| 色彩 | sRGB；暗部不纯黑，保留蓝绿/暖褐层次 |
| 文字 | 不烘焙进 CG；所有可读文字由 Godot 绘制（避免伪造馆藏文字/AI 伪字） |
| 安全区 | 四周 24px（1280 下 48px）不放关键信息；底部 64px 留给字幕/UI |
| 风格 | A v2 像素/半写实混合只允许出现在 CG 层；玩法仍是纯像素 |
| 命名 | `cg_<sceneid>_<slug>.png`，如 `cg_p01_rainhouse.png` |
| 图层 | 至少 `bg` / `subject` / `light` 三层；需要动态的另加 `rain` / `steam` / `reflection` |

## 2. 逐张构图

### P-01 雨屋入行

- **构图**：3/4 侧后屋。左侧门框内是玩家湿透的剪影（背光），中右是老猫低头熨衬衫；熨斗白汽把两人隔开。窗上雨痕，招牌背面透一点红。
- **光**：唯一暖源是台灯/熨斗；玩家一侧冷蓝。老猫的脸半亮半暗，不看清表情。
- **道具**：熨衣板、旧夹克、洗衣粉白斑的手、湿衬衫、白汽、门缝积水。
- **UI/字幕**：底部字幕 2 行内；「三条规矩」用旁白，不弹大段文本框。
- **复用**：安全屋背景的洗衣店语言；可截取 `safehouse_bg` 的材质。
- **禁止**：不要把老猫画成慈父/反派；他是中层，疲惫、现实。

### H-01 两张卡片

- **构图**：俯视 45° 桌面。台灯在左上，光锥落在两张卡片；一张干净、一张皱；两只没戴的白手套在画面边缘；放大镜压住干净卡一角。
- **光**：台灯暖黄，背景阁楼冷褐；卡片是画面唯一高亮。
- **道具**：卡片 1「1936 / 伦敦 / 购自尤摩弗帕勒斯旧藏」；卡片 2「1860 / 圆明园 / 网上抄的」；不要来源行（私人卡片，不是馆方档案）。
- **UI**：卡片文字由 Godot 用展签卡字体绘制；CG 只画纸和光。
- **边界**：1860 卡必须明显更旧、更皱、更像打印/抄写；不得做成馆方正式标签。

### L-01 两张纸（全作最重要 UI 叙事）

- **构图**：正面略低机位。双羊尊在玻璃柜内，暖光池从上方落下；左侧台座贴馆方标签，右侧围栏绳上用透明胶带粘一张皱纸留言。玻璃有两层反光，玩家影子在玻璃里。
- **光**：左羊暖（2700K），右羊冷（6500K）；同框时光池从中间分开，交界在双羊背对背的轮廓上。
- **UI**：标签/留言是**两个可交互物**，不是 CG 里的可读文字；CG 只提供位置与材质。读后 UI 卡片见 §3。
- **边界**：标签写「传出自湖南 / 1936 购自…… / 1936,1118.1」；留言只写「1860，圆明园。别忘了。」；不得把留言做成馆方说明。

### M3 岔路

- **构图**：货车驾驶室内部，挡风玻璃占 2/3；雨刷、仪表盘微光；前方岔路左仓库区、右旧工业区，两个方向都没有路灯。后视镜里是老猫的半张脸。
- **光**：仪表盘冷绿/琥珀，远处车灯很弱；不要给「正确方向」打光。
- **道具**：油表灯、方向盘、后厢木板、两下敲击的视觉暗示（木板微震/灰尘）。
- **UI**：选项只显示地址，不显示「卖/还」；隐藏选项出现时不加金光/提示音。
- **边界**：不画具体真实地址；雨夜、无路灯、工业区是虚构。

### E-01 货（出售）

- **构图**：冷白仓库，正面对称。台秤居中，双羊尊放秤盘；右侧泡沫卷、胶带、木箱；墙上没有窗。老秤在左，戴手套；玩家在右，半身。
- **光**：唯一亮源是头顶白灯，干净得发冷；阴影硬。
- **道具**：台秤、秤砣、泡沫、胶带、木箱、暖气片、旧报纸。
- **UI**：结局卡在画面下方/下一屏；CG 不烘焙「结局一」文字。
- **边界**：交易是虚构；不出现真实买家/真实价格。

### E-02 归（归还）

- **构图**：旧棉纺厂第三排。毛毡桌居中，双羊尊放在毡上；阿岚在左，白手套、旧相机、表格；右侧掉漆保温杯、坏伞。窗外雨，屋里只有工作灯。
- **光**：工作灯暖黄，背景冷灰；没有仪式光/聚光灯。
- **道具**：毛毡、白手套、相机、表格、保温杯、坏伞、雨窗。
- **UI**：表格文字由 Godot 绘制；CG 只画纸与笔。
- **边界**：归还渠道虚构；不主张真实文物已归还；不画官方机构标志。

### E-03 第三只羊（隐藏）

- **构图**：凌晨河边，货车后厢打开；双羊尊在车尾，河面碎光；两羊的影子第一次重合（不是两只实体羊）。远处棉纺厂轮廓。
- **光**：天光冷蓝 + 车尾灯暖红；唯一「暖」是车灯，且很弱。
- **道具**：后厢、绳索、河面、碎石、远处厂房。
- **UI**：结局卡独立；CG 不烘焙文字。
- **边界**：纯意象；不画确定劫掠/火焰；不把「回家」做成胜利烟花。

## 3. 馆方标签 vs 观众留言（UI 规范）

两者必须 **1× 一眼可辨**：形状、材质、字体、边缘、交互反馈都不同。

| 项 | 馆方标签 | 观众留言 |
| --- | --- | --- |
| 底色 | 米白卡纸 `#E9DFC7`，平整 | 皱纸 `#D8C8A8`，带折痕/污渍 |
| 边框 | 1px 金 `#B08A48`，直角 | 无边框；边缘不规则，透明胶带 2 条 |
| 字体 | 印刷体（Fusion Pixel / Noto Serif），字距匀 | 手写体（可用像素手写/略斜），字距不匀 |
| 编号 | 右上角馆藏编号 `1936,1118.1` | **无编号** |
| 来源行 | 有「馆方说明」小字 | 有「观众留言，非馆方说明」朱红小字 |
| 交互 | E 阅读；读后盖「已读」小印 | E 阅读；读后纸角卷起/胶带反光 |
| 尺寸 | 260×150（640 逻辑） | 220×140，略小、略歪 |
| 位置 | 展台正面 | 围栏绳/玻璃边缘，用胶带粘 |

### 3.1 交互状态

- 未读：标签右下角一个小红点；留言胶带有一道高光。
- 已读：标签盖「已读」灰印；留言纸角卷起，红点消失。
- 只读一张：另一张仍显示红点；不弹「你错过了」。
- 两张都读：触发双羊对话；不强制弹窗。

### 3.2 文本边界

- 标签文字只使用 `STORY.md §L-01` 的版本；不要新增馆藏编号/年代。
- 留言只保留一句；不要扩写成论文。
- 不把 1860 圆明园写成馆方结论；UI 必须标「观众留言，非馆方说明」。

## 4. 双羊双声道字幕

### 4.1 声音

- 左羊：左声道，低、慢、干；呼吸间隔长。
- 右羊：右声道，急、带气声/海腥味；句尾短。
- 同时说话：不叠成合唱；每条字幕独立出现，允许 0.2s 交叠。
- 环境：标签场景无音乐；只有纸、玻璃、远处脚步。

### 4.2 字幕签条（640×360）

| 项 | 左羊 | 右羊 |
| --- | --- | --- |
| 位置 | 对话框左上，向左对齐 | 对话框右上，向右对齐 |
| 颜色 | 暖金 `#D8A84E` | 冷青 `#7FA8B8` |
| 签名 | 「左羊」/ 无 | 「右羊」/ 无 |
| 字号 | 10px | 10px |
| 最大字数 | 单行 ≤ 18 字，最多 2 行 | 单行 ≤ 16 字，最多 2 行 |
| 动效 | 淡入 0.2s，停留 ≥ 1.6s | 淡入 0.15s，停留 ≥ 1.2s |
| 同时 | 左条在上、右条在下；不重叠 | 同左 |

- 说话人签条不抢正文；正文仍在对话框内，签条只做「方向」提示。
- 没有语音时，字幕也必须能独立读懂；不要依赖声道。
- 关键句（「别把我包起来」「我不记得火」）可加 0.3s 停顿，不加屏幕震动。

## 5. 结局卡

### 5.1 版式（640×360）

- 背景：黑/深褐 `#0B0F12`，底部 1px 金线。
- 标题：12–14px，左对齐；「结局一 · 货」「结局二 · 归」「结局三 · 第三只羊」。
- 正文：9–10px，3–5 行；行距 14px。
- 史实声明区：下方 1/4，米白/灰纸底；8px；必须原样出现 STORY 中的声明。
- 按钮：继续/回据点，右下；金色描边，不要大红大金。
- 不使用「胜利/失败」「你选对了/错了」字样。

### 5.2 三张卡的差异

| 结局 | 标题色 | 声明区 | 氛围 |
| --- | --- | --- | --- |
| E-01 货 | 冷白 `#D8D0BE` | 灰纸，硬边 | 干净、冷、无窗 |
| E-02 归 | 暖金 `#D8A84E` | 米纸，软边 | 暖灯、毛毡、雨 |
| E-03 第三只羊 | 青灰 `#9FB8B0` | 米纸 + 河蓝细线 | 天光、河面、重合影子 |

> 声明文字由 `STORY.md` §E-01/E-02/E-03 提供；不得改写史实边界。
