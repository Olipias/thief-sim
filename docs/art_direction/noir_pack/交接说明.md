# 《小偷模拟器》美术统一交接

用户选定：玩家以 `thief_turnaround_a.png` 为基准；警察以深蓝制服 `a00_police_concept_v2.png` 为基准；场景采用 A 方向冷色像素博物馆、暖色文物。本包汇总玩家、警察、安全屋、手机和博物馆一轮素材。

## 目录

- `assets/sprites/chars/`：玩家和警察 24×32、4 列 × 3 行透明帧表。行：下、上、右（左镜像）；列：待机、待机、行走 A、行走 B。脚底锚点 y=-10。
- `assets/art/`：1280×720 安全屋背景、96×96 手机九宫格边框（切片边距 12）。
- `assets/sprites/bm/`：六展厅主题墙地与红毯图集、目标文物玻璃罩和 16 个场景装饰；三个展柜重新绘制，其余装饰在原造型上统一配色。图集索引与装饰尺寸保持原样。
- `tools/`：生成脚本；依赖 Pillow，`gen_noir_art.py` 还以项目已有 `assets/sprites/bm/bm_tiles.png` 和 `assets/sprites/bm/decor/` 为基础。生成原图保存在 `docs/art_direction/a00_src/`，方向稿仅供参考。不要直接手改生成 PNG。
- `preview/`：角色帧表、安全屋、手机和六展厅 Godot 截图。
- `接入参考.patch`：本副本中场景、手机样式、博物馆贴图引用及测试的差异。先阅读再依据目标项目当前代码手动合并，不要盲目覆盖并行工作。Godot 会重新生成 `.import` 文件。

## 接入与核对

1. 查看目标项目的 `git status`、路线图及相关文件，确认没有冲突。按目录复制资源和脚本。
2. 按补丁将 `player.tscn`、`police.tscn`、`hub.tscn`、`mission_phone.tscn`、`museum.gd` 指向新资源；手机按钮选中样式也在补丁中。更新 `tests/test_scenes.gd` 的资源检查。不要改变碰撞、按键和关卡数据。
3. 查看脚本与生成素材是否一致，导入资源；运行 `tools/verify.sh --visual`，审查并在预期变化确认后更新截图基线。按 `docs/MANUAL_QA.md` 试玩。

## 验证与限制

Windows Godot 4.7.2：场景测试 110 项、输入流 105 项、内容 567 项、600 步 monkey 和 162 项冒烟通过；上一轮逻辑、存档、进度、剧情检查通过，Windows 上存档测试需要将临时副本里的 `/tmp` 改为 `C:/tmp`。截图场景也使用临时 Windows 路径，已查看六展厅、手机和安全屋截图。

原版 Linux `tools/verify.sh --visual`、视觉基线更新和完整手动试玩尚未完成。警察在很暗的房间可能仍需提亮；手机实际接入了边框和标签样式，方向稿中的装饰细节未全部复制。普通教学关的通用场景资源、原有文物图和特效继续使用项目既有素材；本包重点是大英博物馆六展厅。场景、手机和安全屋的图像生成素材需再由项目维护者按最终美术标准审核。
