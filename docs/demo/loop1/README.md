# Loop 1课堂展示：约55–70秒

先打开同目录index.html（双击即可，无服务器、网络、CDN或安装依赖）。页面有四页，点击上方页签或按左右方向键切换。另开原始聊天与根目录plan.md、goal.md；进入课堂前完成打开。

## 展示顺序与讲稿

| 时间 | 屏幕操作 | 可直接讲的内容 |
| --- | --- | --- |
| 0–15秒 | 第一页“需求讨论”，指向一条原话；短切原始聊天上下文 | “这是我和agent讨论玩法的真实记录。我先要求规划再开发，并明确主要文物走剧情交付。根据讨论，agent把决定整理进确认方案。” |
| 15–30秒 | 第二页“目标与计划”；短切goal.md与plan.md文件 | “我的目标是让玩家通过文物调查和路线预演作出选择。计划里先验证预演的一致性，再逐项做场景与设备。这次课堂优先展示能玩的桌面切片。” |
| 30–45秒 | 第三页“项目结构图” | “这张图由agent生成。上面是玩法模块，中间是预演机制，下面是共享内容数据与测试。虚线代表后续设计；我接下来演示实线部分，并现场运行测试。” |
| 45–60秒 | 第四页“Agent 协作进展” | “这是通过 agentchattr 读到的真实协作记录：plan 发设计校准，code 实现，test 独立验收并找缺陷，art 待命。v0.20 移除幽灵、v0.22 确定性预演灰盒、v0.23 q6 开场与标题 UI，都是多 agent 并行完成的。” |

讲稿可按本人表达缩短；没有展示过的内容不说“刚才展示了”。无需在Loop 1展开三件文物历史或完整技术细节。

| 原要求 | 材料 | 当前边界 |

## 课前核对

- 离线打开index.html，试三个页签、左右方向键；图和中文正常显示。
- 原始聊天停在“先plan一下吧”“三件主要文物是走剧情的”或“每隔5秒”的一段，避免现场搜索。
- plan.md与goal.md在编辑器预先打开。HTML页签切换正常不等于原始聊天证据已准备。
- 不演示本页为游戏网站，不把本地file地址说成老师要求的live HTTPS URL。本页只用于Loop 1。
- 当前图的实线仅表示存在代码模块，不代表所有关卡和全部剧情已验收；待实现的完整安全屋、手机门口出发与箱子交易在虚线区域。

可用浏览器打印保存PDF作为备用；原始聊天仍单独展示。本轮没有生成任何冒充聊天界面的图片。
