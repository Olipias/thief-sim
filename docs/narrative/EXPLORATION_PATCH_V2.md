# 探索循环的剧情与调查文本补丁 V2

日期：2026-11-19。配套[探索方案](../EXPLORATION_LOOP.md)，仅供后续接入，不表示已在试玩包生效。本文取代V1的局外完整照片、三条链齐全才出发和布展单直接定位等安排；其余历史条目继续按V1审校映射核查。具体对白仍是可调整文本稿。

## 1. 三个名字代替三张照片

教学交面具后，恶魔留下一张写有三件目标名称的清单，无照片和全地图。既有三件文物素材保留，只有现场观察后才进入玩家的实物记录。原A03、A04中的发照片、按照片认物和所有相关触发条件随之替换。

恶魔：面具给我。接下来，从这三件里带回一件。

我：只有名字？

恶魔：其他的，你自己查。

我：先得知道该找什么。

任务提示：查看清单，联系老猫。手机可准备侦察，不要求先完成三条调查。

老猫：我给你个联系人。她能帮你查来历。

阿岚：把名字发来。查到的资料我转给你。

阿岚：展位得去现场找。看见后，记下柜号。

这里的“只留名字”不表示恶魔改变任务条件或新增时间惩罚；不补写其终极动机。契约后果沿用另待用户审阅的剧情，不因本补丁确认死亡代价。

## 2. 推理问题改成可逐趟回答

每条线中央先放文字任务档案，周围三个问题：

- 它有哪些能认出的特点？
- 哪份材料指向本次展区？
- 我在哪里看到过对应门牌或柜号？

未见实物时用文字卡，不用已有模型渲染图提前代替照片。现场观察后出现实物记录，再核对描述、柜号与展签。只追踪一条线也能行动，另外两条未完成不阻塞出门。

V1的zun_photo、scarab_photo、askos_photo在新稿中的叙事位置改为“现场观察记录”。这些是文本用途调整；接入时不得直接重释旧存档已获得的photo ID，须保留旧记录并新增明确状态或迁移。接收方可以先按名称/公开编号提供资料，只有实地取得照片后才能说“照片收到了”。

布展单示例：“东厅G-04，经南侧服务间维护。”它只能给出待找地点与局部关系；未到东厅时不生成地图点。对应门牌/柜号真正见到后，玩家可手动关联。错把考古“西屋”连成展馆西翼时，提示：

这张材料写的是出土地，还缺本次展位信息。

不自动补出东厅、钥匙和全部后续关系。现场核对成功可以当次取物；电脑用于整理与回看，不为强制重复潜入再加一道解锁。

## 3. 第一次侦察回来也有剧情

触发：正常撤离，带回普通战利品但没有主要文物。只播放一次简短提示，不触发交主要文物的p05，不扣命或虚构违约失败。

我：目标还没找到，倒是看见了服务门。

老猫：小件先放箱里。要卖，就在手机约我。

我：下次从服务间过去看看。

如果没有普通战利品，改为“门牌记下了，下次不用再绕。”不得在没发现对应信息时强播该句。无新收获时给具体未解问题，不假装玩家已经找到门。

## 4. 出售、采购与下次准备

普通交易沿用箱子存放、手机预约、取货、门外验货；主文物不出现在报价里。

门外人：货齐了。钱转给你。

手机采购页示例：

- 烟雾弹：遇险时遮挡视线。消耗品。
- 跑鞋：提高疾跑速度。永久装备。
- 撬锁工具：打开标有可撬锁的维护门。也可在馆内找钥匙。

采购只在住处确认，备货后下次携带；不增加等快递的剧情。正式商品数值以实际代码为准，不把跑鞋写成完全无声。

## 5. 取回主目标后

只有真正带回其中一件主目标，才进入恶魔或对应国家的交付抉择；不要求另外两条线完成。此前积累的地图与普通物品保留，不把侦察撤离写成已履行契约。

本补丁只增加虚构展馆行动、联系人说话顺序与购物说明，不增加现实文物事实或追索主张。历史知识仍取自已核查事实ID；完整创作说明与来源仍统一放标题“声明”。
