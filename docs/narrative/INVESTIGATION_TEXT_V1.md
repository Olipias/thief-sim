## 一、采用《师父》的哪些做法

参考Sloclap对《师父》调查板的说明：保留已经搜集的调查信息，把人物、线索与已发现的门和捷径放在一起，方便重试时接着调查。原始说明见[开发者文章](https://blog.playstation.com/?p=356878)。

本作采用三个以文物照片为中心的线索区，人物头像、邮件、展签、布展单逐步贴上去。已找到的内容持续保留；可见空白问题，不提前显示答案。玩家可以从房内电脑回看，也能在手机查看已记录的要点。

手动拖卡、选择关系、错误反馈是本项目既有要求的延伸，不冒称是《师父》原有的同一套连线规则。游戏不照搬其复仇人物关系或文字。

## 二、板面与记录方式

每件文物中央是一张照片，周围先留三个问题：

- 照片里是哪一件？
- 这次摆在哪里？
- 怎样到达并带走？

接收方是旁侧的人物节点，连到文物与邮件。它给玩家提供另一条交付去向，不作为接恶魔任务的道德门槛。

线索状态：还没找到 / 已找到，待核对 / 已核对 / 仍有疑问。

卡片正面只显示标题和一句要点；打开后看正文、图片或附件。UI不显示事实ID、X类标签、代码路径或“此为虚构”。来源性质、核查范围和作者ID留在编辑记录，完整说明集中标题声明。网页、邮件、展签仍保留各自正常的署名与文书标题。

玩家连线后选一个具体关系，不只问“相关/无关”。结论只补上已被这次判断回答的那个问题，不自动补出其余关系。错误连线不会扣命，也不触发恶魔惩罚。

核心规则：三条线都完成身份、展位和通路的核对后，可在手机选择本次一件目标。可选历史卡不阻塞出发；未提前联系接收人的玩家可在交付前补发材料，不锁死归还分支。

以下ID与条件供开发，卡片标题/要点/正文才给玩家看。旧有九个线索ID保留，新增卡片需后续接入与老档兼容。

## 三、中国线：双羊尊

### zun_photo · 三张照片之一

位置：住处桌面，查看清单后获得。

正面标题：背靠背的两只羊

正面要点：两只羊支撑着中间的器身。

正文：照片能看见两侧的羊头和背上的开口。背面抄着一串编号：1936,1118.1。角上画着一个小圈，旁边写着“别抓这里”。

编辑映射：形制按C-001-F03；背面字迹、圈记为X-C01。照片内须实际呈现玩家要辨认的两侧羊头与开口，不要求玩家从像素模糊图猜答案。

### zun_archive · 馆藏档案

位置：电脑档案库，用照片背面的编号检索。

正面标题：1936,1118.1

正面要点：登记对象是商代双羊尊。

正文：两只羊合为器身，背部有开口。档案记载它来自尤摩弗帕勒斯旧藏，1936年入藏。关于此前的出境经过，这页没有继续写下去。

编辑映射：C-001-F01/F02/F03、C-001-U01。1936年字段沿用项目既有登记；馆方页面本轮403，正式接入前补复核，不把研究中的“1930年代”自行精确化。

### zun_tech · 浏览器研究摘记

位置：从档案中的研究条目打开，不靠漫无边际猜关键词。

正面标题：羊角是先铸的

正面要点：接合痕不等于后来修补。

正文：这件双羊尊做过技术研究：羊角先铸好，再与器身接合。材料也讨论了南方青铜传统，具体来自湖南何处仍不能确定。

编辑映射：C-001-F04/F05。用途说明在可展开的沈先生对话中保留不确定性，不把器名直接当成已经证实的具体使用场景。

### zun_delivery · 布展工作单

位置：向阿岚回复照片与编号，收到邮件附件。

正面标题：C-17搬运备注

正面要点：腹底托垫，角部避让。

正文：C-17：双羊尊，1936,1118.1。入柜时从腹底托起，避开双角。临时展位在青铜厅内侧。送柜和撤柜都走东侧装卸道。

编辑映射：X-C02。C-17、展位和路线均为新稿场景设计，接入时必须对应实际地图，不能把文字写了就算开门功能完成。

### zun_service · 馆内检修便条

位置：青铜厅外服务通道，可在不接触目标的情况下先读到。

正面标题：东侧装卸道

正面要点：C-17与这条道在同一张单上。

正文：C-17的搬运小车停在东门内侧。台阶口不得搬运重器，请从平坡绕行。搬运结束后关闭防火门。

编辑映射：X-C03。小车、平坡与防火门需在场景中可见；本稿不强加新的推车小游戏。旧地图不满足时，后续agent须落实或将路线改为实际可走通的服务门。

### zun_chat · 沈先生的确认

位置：手机联系人，通过阿岚介绍后发去编号与照片。

正面标题：沈先生 · 核对材料

正面要点：实物、照片、记录一并接收。

正文：照片和编号我收到了。你若决定交给我们，别把文件留在原地。此前查不到的部分先空着，这次的交接要写清。

编辑映射：X-C04。人物身份与接收渠道在主剧情首次通话交代；不伪装成现实中国机构针对本件已发出的追索函。

### zun_history_gap · 可选调查页

位置：档案库“流转记录”的下一页。

正面标题：收藏家之前

正面要点：这份材料没有写。

正文：我能接上的一段，是收藏家旧藏到博物馆。再往前暂时缺记录。先不把别处看到的故事填进来。

## 六、跨文物误连与板面通用文本

不把三个展厅串成同一段流转史。可让玩家误连，但要指出哪一条信息不匹配。

| 情况 | 屏幕反馈 |
| --- | --- |
| 把1910捐赠单接到双羊尊 | 捐赠单的编号是10.130.1650，和照片背面的编号不同。 |
| 把1936记录接到圣甲虫护符 | 这份记录写的是双羊尊。先核对物件与编号。 |
| 只按“都来自国外”连接两件 | 还缺两条材料之间的具体联系。 |
| 已找到关键卡，但关系未选 | 两张卡都在。再选一下它们能说明什么。 |
| 拖到了空白问题上 | 这里还缺一条线索。先看看哪些附件没读。 |
| 尚未在馆内找到入口 | 纸上标了通路。进馆后还要确认门在哪里。 |
| 重复搜集同一条 | 板上已有这条记录。 |
| 行动失败重来 | 调查记录保留。修改路线后再出发。 |
| 只差可选历史卡 | 本次行动已可准备，剩余资料可稍后读。 |

提示分级：

1. 第一次停住：板上还有〔材料标题〕没核对。
2. 再次请求：对照两张材料上的编号/器形/展位。
3. 玩家主动点“详细提示”：给出需要比较的两个字段，但不自动替玩家连线或改变完成状态。

成功后短句按问题变化，不统一弹“恭喜完成推理”：

- 身份：照片和记录对上了。
- 展位：找到它这次摆的位置了。
- 通路：入口先记在地图上。
- 联系：回信到了，可以安排交接。

## 八、接入约束

- 三条线各七张卡，包含可选阅读与接收节点；关系表里的核心身份/展位/通路是行动门槛，历史拓展与接收联络不强迫玩家选立场。

- 本批没有新增运行时卡片、存档字段或完成标记。后续新增字段仍需老档默认值、脏档与丢失线索补发测试。
