## 1. 两个技能的实际使用

- stop-slop：读取本机 `/home/liyutong/.config/opencode/skills/stop-slop/SKILL.md`，并检查references中的phrases、structures、examples。用于先写后删空话、假对比、格言式收尾和无人物动机的句子。
- Humanizer-zh：本机技能目录未找到，读取[op7418/Humanizer-zh上游SKILL.md](https://github.com/op7418/Humanizer-zh/blob/main/SKILL.md)与[原始正文](https://raw.githubusercontent.com/op7418/Humanizer-zh/main/SKILL.md)，元数据revision为2026-09-23。本轮未安装技能或改变全局环境。按其“保留事实、确定程度、文体和作者声音”的流程做第二遍检查。
- stop-slop先检查模板表达；Humanizer-zh再核对内容有没有被删错、语气是否变成统一腔调。表达时间顺序的“先/再”、有实际信息的否定和不确定用语保留，不把文风规则机械执行成删事实。
- 不承诺绕过AI检测，不使用检测器分数证明“像人写的”。后续agent需要复审时，应读取上述技能，不只照抄本记录称“已检查”。

## 2. 实际改写检查

对照对象来自当前src/data/story.gd/evidence.gd的旧句，不是伪造用户反馈。

| 旧表达或问题 | 本稿处理 | 审查重点 |
| --- | --- | --- |
| “我是替东西收信的人。” | 阿岚先说明“我替接收方核对材料”，再说明照片、档案和交接分别能办什么 | 人物有身份，玩家知道为何联系 |
| “东西没有家。人有。” | 删除口号；让老猫交代戒指抵款、欠钱、介绍阿岚的具体原因 | stop-slop：不以格言代替剧情 |
| 教学完成后再派面具任务 | A03直接交面具并收到三张照片 | 修正前后因果，不把旧段落全拼回去 |
| 1936/1860“你信哪张”式二选一 | 把能查的一段与材料缺口分开，正文不再靠这条传闻制造抉择 | Humanizer-zh：不把未知改成确定，也不把购买和掠夺写成互斥命题 |
| 【虚构邮件】等反复打断正文 | 正文保留正常邮件/展签标题；作者映射和标题声明承担边界说明 | 沉浸与资料可追溯分别落实 |
| “它不再是任何人的私产。” | 改为本次接收人核对状态、签收与记录交接 | 不编造所有权/法律结论 |
| 用同类心脏圣甲虫的30B章替本件写铭文 | 莱拉明确区分同类介绍与本件照片，不新增本件刻文 | 不混用件目 |
| 文物有声音、有人在夜里笑 | 主线移除；面具只作观察，不恢复器灵 | 维持已确认边界 |
| 中国结局的1936移到其他两件 | 三件分别写接收变体 | 不模板套错历史资料 |
| 结局又让濒危主角复述年代 | 把知识保留在调查阶段，接收人先扶住主角并叫人，收件单只作本次交接凭据 | 保留人物对处境的正常反应，不把死亡场景写成历史测验 |
| 用一长段资料说明全部知识 | 拆到照片、材料、操作单、可选通话和实地核对 | 知识参加调查，默认不强制背诵 |

内部复核：已通读人物口吻、句长、空话与事实限定；这不等于文本已经完成用户验收。不提供虚假的独立评分或“AI味完全消失”结论。
